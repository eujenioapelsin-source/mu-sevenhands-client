# MU: Testament of the Seven Hands - public test client
Public test build v0.1.0.
## Install
1. Get SevenHands Launcher from the admin.
2. Run the launcher (admin rights required).
3. Press PLAY: the launcher verifies/updates main.exe from this release and starts the game.
## Contents
- main.exe - vanilla S6 Ep3 client executable (test build).
- manifest.json - version manifest (sha256 / size / urls / news) used by the launcher.
